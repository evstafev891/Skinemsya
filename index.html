Скидываемся на общее дело

Подарок, аренда дома на выходные, общий ужин — организатор создаёт сбор, остальные присоединяются по QR-коду и переводят деньги ему по СБП. Здесь видно, кто уже скинулся и сколько осталось.

Создать сбор Как это работает

Сначала попросим имя и телефон для СБП — на этот номер участники будут переводить деньги. Чтобы присоединиться к чужому сбору, откройте ссылку или QR-код от организатора.

Страница не загрузилась

Скрипты сайта не запустились. Частые причины:

  • файл открыт с диска двойным кликом — откройте сайт по адресу github.io или через локальный сервер;
  • в js/config.js ошибка после вставки настроек Firebase — оставьте строку export const FIREBASE_CONFIG = { и замените только значения внутри скобок.

Точный текст ошибки виден в консоли браузера (F12 → Console).
